# Сайт группы VДМП-105уцп

Командный учебный проект по управлению коллективной разработкой приложений.

## Как распределить работу

Каждому участнику назначается одна полноценная страница-резюме:

| Участник | Файл |
|---|---|
| Данил | `members/member-01.html` |
| Участник 2 | `members/member-02.html` |
| Участник 3 | `members/member-03.html` |
| Участник 4 | `members/member-04.html` |
| Участник 5 | `members/member-05.html` |
| Участник 6 | `members/member-06.html` |
| Участник 7 | `members/member-07.html` |
| Участник 8 | `members/member-08.html` |
| Егор Рудченко | `members/member-09.html` |

Если участников меньше, лишние карточки удаляются из `index.html`. Если больше — копируется последняя карточка и добавляется ещё один `iframe`.

## Что делает каждый участник

1. Принимает приглашение Collaborator от владельца репозитория.
2. Клонирует основной репозиторий.
3. Создаёт личную ветку `member/фамилия`.
4. Заполняет резюме только в назначенном файле из папки `members`.
5. Делает commit и push в личную ветку.
6. Открывает pull request из личной ветки в `main`.

Прямой push в `main` запрещён. Участники могут отправлять только отдельные ветки, а проверить и объединить pull request может только владелец проекта.

Подробные команды находятся в [CONTRIBUTING.md](CONTRIBUTING.md).

## Запуск сайта

Откройте `index.html` в браузере. На главной отображаются превью резюме, а по нажатию открывается полная страница участника. Сборка и установка зависимостей не нужны.
