# Как добавить свой вклад

Все команды выполняются в терминале из папки проекта.

## 1. Получить проект

```bash
git clone АДРЕС_РЕПОЗИТОРИЯ
cd Сайт_группы_VДМП-105уцп
```

## 2. Создать личную ветку

Вместо `surname` укажите свою фамилию латиницей.

```bash
git switch -c member/surname
```

## 3. Заполнить свою карточку

Откройте назначенный файл `members/member-XX.html` и замените:

- инициалы;
- имя и фамилию;
- короткое описание;
- навыки.

Не редактируйте чужие карточки.

## 4. Сделать commit

Пример для второго участника:

```bash
git add members/member-02.html
git commit -m "Add profile: surname"
```

## 5. Отправить изменения

```bash
git push -u origin member/surname
```

## 6. Открыть pull request

На странице репозитория GitHub нажмите `Compare & pull request`, добавьте короткое описание и создайте pull request в `main`.

После объединения pull request вклад участника останется виден во вкладках `Commits` и `Pull requests`.
