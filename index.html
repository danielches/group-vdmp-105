О группе

Один сайт — разные участники

Мы учимся совместно разрабатывать проект: распределяем задачи, работаем в отдельных ветках и объединяем изменения через pull request.

Команда

Участники проекта

Каждый участник редактирует только свой файл в папке members.

Совместная разработка

Как появляется общий результат

  1. 01

    Получить проект

    Клонировать общий репозиторий на компьютер.

  2. 02

    Создать ветку

    Работать в ветке со своим именем, не в main.

  3. 03

    Добавить профиль

    Заполнить закреплённый файл участника.

  4. 04

    Сделать push

    Отправить ветку в GitHub из личного аккаунта.

  5. 05

    Открыть pull request

    Проверить изменения и добавить их в общий сайт.

Результат

Вклад каждого виден в GitHub

Коммиты, ветки и pull request показывают, кто и какую часть сайта сделал.

Команды участника git add members/member-02.html git commit -m "Add member profile" git push -u origin member/name
